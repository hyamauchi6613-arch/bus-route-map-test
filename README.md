# しずてつ路線クイズ：実地図移行スターター

このパッケージは、提供された `index 1.html` の既存データを分離するための準備資料です。**まだ完成版アプリではありません。**

## 内容
- `map-editor.html`：地図をタップして停留所の座標を登録し、`stops.json` を書き出す試作ツール（HTTP/HTTPS環境で使用）。
- `data/routes.json`：既存 `SAMPLE` から抽出した路線名・停留所順・メモ・営業所。
- `data/stops.json`：路線データに登場する停留所名を重複除去した一覧。緯度経度は意図的に未設定。
- `data/route-geometry.geojson`：今後、確認済みの走行経路を入れるための空テンプレート。
- `docs/analysis-and-next-steps.md`：現状分析と安全な移行手順。

## 大事な注意
1. 元アプリの `GEO` は図上のピクセル座標です。緯度・経度ではないため、実地図にそのまま使えません。
2. `routes.json` は元ファイルから機械的に移したものです。停留所順や路線情報の正確性を再検証したものではありません。
3. 座標が未確認の停留所は地図上に正しい位置として表示しないでください。
4. 実際の道路に沿う線を引くには、停留所の座標とは別に経路形状の確認が必要です。
5. `routes.json` と `stops.json` は現時点では名前で関連づける簡易構成です。今後、重複する同名停留所や方向違いを確認し、安定したIDで参照する構成にするのが理想です。

## 座標登録ツールの使い方
1. このフォルダをGitHub PagesなどHTTP/HTTPSで開ける場所へアップロードします。ZIPを解凍した後、`map-editor.html` と `data/` フォルダの位置関係を維持してください。
2. `map-editor.html` を開き、停留所を検索して選びます。
3. 地図を拡大し、公式資料などで場所を確認したうえで、地図上をタップします。
4. 「JSONを書き出す」で `stops.json` を保存します。ブラウザ内保存は同じ端末・同じブラウザ内の一時的な編集用です。永続化にはJSONの書き出しが必要です。
5. 地図の出典表示を消さないでください。OpenStreetMap標準タイルはオフライン利用や先読みダウンロードに使えません。

## 次の実装
1. このJSONを読み込むように既存アプリの路線データ読込部分を変更する。
2. Leaflet + 適切な地図タイルを使って地図を表示する（タイル提供元の利用条件・帰属表示を守る）。
3. 位置未確認の停留所は「未配置リスト」に表示する。
4. 地図をタップして位置を登録・修正し、JSONをエクスポートできる編集モードを作る。
5. 最初は1路線だけ座標と経路を検証してから範囲を広げる。
